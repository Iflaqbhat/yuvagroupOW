# Amenity photos needed

Drop the photos in this folder (`public/photos/amenities/`) using the exact file names below.
The site will serve them at `/photos/amenities/<name>`.

## Required (10)

| File name | Amenity | What to look for |
|---|---|---|
| `clubhouse.jpg` | Clubhouse | Clubhouse building/exterior or lounge |
| `swimming-pool.jpg` | Swimming pool | Pool with loungers, daytime |
| `gymnasium.jpg` | Gymnasium | Gym equipment, bright interior |
| `landscaped-gardens.jpg` | Landscaped gardens | Green gardens / courtyard |
| `childrens-play-area.jpg` | Children's play area | Play equipment, colourful |
| `jogging-track.jpg` | Walking / jogging track | Paved walking path through greenery |
| `indoor-games.jpg` | Indoor games | Table tennis / billiards / games room |
| `multipurpose-hall.jpg` | Multipurpose hall | Party/community hall interior |
| `banquet-hall.jpg` | Banquet hall | Banquet / celebration space |
| `rainwater-harvesting.jpg` | Rainwater harvesting | Eco/green feature — rooftop garden, water feature, or landscaping |

## Optional (nice to have)

| File name | Amenity | Notes |
|---|---|---|
| `covered-parking.jpg` | Covered parking | Multi-level or shaded parking |
| `metro-facility.jpg` | Metro facility | Nearby metro station / transit |

## Specs

- Landscape orientation, minimum 1000px wide (1600px ideal)
- JPG or WebP, ideally under 300 KB each
- No text overlays or watermarks
- Anything sourced from a free stock site (Pexels/Unsplash) is fine

## Not needed

- `24/7 security` and `power backup` are not photogenic — they stay as small icon chips in the UI.
